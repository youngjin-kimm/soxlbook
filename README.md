# DP chips 교과서 · 투자 기초 개념 교과서

SOXL을 사례로 복리, 주문, 지표, 위험, 확률과 투자 심리를 배우는 인터랙티브 교과서. 11개 학습 장, 19개 개념 실험, 용어집, 해설 퀴즈를 제공합니다.

모든 실험은 가상 수치이며 실제 수익률이나 미래 예측을 나타내지 않습니다. 파이썬 코드 블록은 제외했습니다.

배포 파일 index.html에는 스타일, 글꼴과 동작이 모두 포함되어 있습니다. GitHub Pages는 main 브랜치 루트에서 게시합니다.

이론 자료: https://chatgpt.com/share/6ac4991c-613c-83ee-ba64-248b9069ad3f?ogimg=plain

학습 구성 참고: https://socbook.euiyun.com/

주문과 지표는 3개 주제, 수익과 위험 읽기는 5개 주제로 묶어 장 안의 탭으로 공부합니다. 기존 주제 링크도 그대로 사용할 수 있습니다.


## 본문 복원
원문 20개 학습 주제를 11장에 묶어 설명·비유·사례·한계·학습 질문을 수록했습니다. 파이썬 코드 블록만 제외합니다. IS/OOS, Walk-Forward, Monte Carlo, 견고성, 도구 활용, 자동화와 전략 중단의 개념을 포함합니다. 19개 실험은 가상 수치로 원리를 설명합니다.
